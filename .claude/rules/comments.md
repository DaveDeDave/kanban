# Comment Rules

- In complex flows, add a comment explaining what the code does and, especially, why it exists.
- In simple flows, avoid comments unless the code is unclear.

  - Avoid: `const sum = a + b; // Sum a and b.`

- Add a comment above `useEffect` when its purpose is not obvious or the effect contains a long, unclear callback. Explain what it does and why it exists.
- Keep comments short and clear.
